# 题目描述
239 滑动窗口最大值
https://leetcode.cn/problems/sliding-window-maximum/description/

假设一个固定大小为W的窗口，依次划过arr，
返回每一次滑出状况的最大值

例如，arr = [4,3,5,4,3,3,6,7], W = 3
返回：[5,5,5,4,6,7]

# 题解
1. 准备一个最大值窗口队列maxQueue，窗口队列中存的数组下标，从左到右遍历数组
2. 如果当前值大于等于队列中最后一个值，弹出队列最后一个值
3. 将当前数下标放入窗口末尾
4. 如果当前值下标R减去窗口大小w等于队列头部下标，则弹出第一个
