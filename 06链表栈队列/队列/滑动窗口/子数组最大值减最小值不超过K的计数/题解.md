# 题目描述
给定一个整型数组arr，和一个整数num

某个arr中的子数组sub，如果想达标，必须满足：

sub中最大值 – sub中最小值 <= num，

返回arr中达标子数组的数量

# 题解
核心思想：
1. 维护一个最大值窗口队列maxQueue和最小值窗口队列minQueue，队列中存下标
2. 维护两个指针L和R，L～R满足小于等于num，那么L~R之间的数也一定满足
3. R移动到第一个不满足条件的时候停
4. L移动到第一个满足条件的时候停
5. 核心含义是每次计算，从L出发，一共有多少个满足，可以直接通过窗口算出来
6. L在加一之前，检查最大最小窗口，该弹出弹出
