# 题目描述
155 最小栈 
https://leetcode.cn/problems/min-stack/description/

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

MinStack() 初始化堆栈对象。
void push(int value) 将元素 value 推入堆栈。
void pop() 删除堆栈顶部的元素。
int top() 获取堆栈顶部的元素。
int getMin() 获取堆栈中的最小元素。

# 题解
1. 设计一个数据栈，一个最小栈
2. 数据栈：正常压入弹出数据
3. 最小栈：每次压入最小的val，如果要压入的数据比栈顶大，则重复压入栈顶元素
