# 题目描述
907 子数组最小值之和 https://leetcode.com/problems/sum-of-subarray-minimums/description/

给定一个数组arr，
返回所有子数组最小值的累加和

# 题解
[5,3,1,2,4]
## 核心思想
必须以位置i为最小值的子数组中，一共有多少个这样的子数组，子数组必须穿过i位置
相等情况：当作小于来处理，弹栈，这样能防止重复计算


## 思考步骤
1. 必须以i位置为最小值的子数组中，计算有多少个子数组，子数组必须穿过i位置
2. 定义left为左边小于i的位置，定义right为右边小于i的位置，子数组数量：(i - left) * (right - i)
3. 使用一个单调栈，单调递增，找左右两边比当前数小的数在哪儿
4. 相等情况：当作小于来处理，弹栈，这样能防止重复计算

## 注意
返回值可能比较大，最开始定义ans的时候，使用long类型，每次ans计算后都需要%1000000007
