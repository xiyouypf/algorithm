# 题目描述
N皇后问题是指在N*N的棋盘上要摆N个皇后，
要求任何两个皇后不同行、不同列， 也不在同一条斜线上
给定一个整数n，返回n皇后的摆法有多少种。n=1，返回1
n=2或3，2皇后和3皇后问题无论怎么摆都不行，返回0
n=8，返回92

# 题解：
当前以n=15来解析

## 核心思路
从第0行往后尝试，每一行应该放哪一列  
row代表当前来到哪一行，col代表当前来到哪一列  
record[]里面存储的每一行放的哪一列，record[row]=col代表，row行放的col列

## base case：
当前行row来到n位置时，说明已经全部放完，找到一种方法

整体顺序：大方向row从小到大尝试，col从小到大尝试
