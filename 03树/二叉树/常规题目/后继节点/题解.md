# 题目描述
给你二叉树中的某个节点，返回该节点的后继节点

    public static class Node {
        public int value;
        public Node left;
        public Node right;
        public Node parent;

        public Node(int data) {
            this.value = data;
        }
    }

# 题解
有左树：不考虑
有右树：右节点的最左节点
当前节点是父节点的左孩子：父节点
当前节点是父节点的右孩子：一直找父节点，直到节点是父节点的左节点为止
