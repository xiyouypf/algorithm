# 题目描述
1373 二叉搜索子树的最大键值和 https://leetcode.cn/problems/maximum-sum-bst-in-binary-tree/description/

给你一棵以 root 为根的 二叉树 ，请你返回 任意 二叉搜索子树的最大键值和。

二叉搜索树的定义如下：
1. 任意节点的左子树中的键值都 小于 此节点的键值。
2. 任意节点的右子树中的键值都 大于 此节点的键值。
3. 任意节点的左子树和右子树都是二叉搜索树。

# 题解
## 信息收集：
每棵子树收集5个信息：最小值、最大值、是否二叉搜索树、总键值和、最大键值和

## 空节点设置
1. 最小值：Integer.MAX_VALUE
2. 最大值：Integer.MIN_VALUE
3. 是否二叉搜索树：true
4. 总键值和：0
5. 最大键值和：0

## 当前节点信息封装：
1. 最小值：当前节点值、左树最小值、右树最小值，三者取最小
2. 最大值：当前节点值、左树最大值、右树最大值，三者取最大
3. 是否二叉搜索树：
    1. 左树是搜索二叉树、右树是搜索二叉树
    2. 当前节点值大于左树最大值
    3. 当前节点值小于右树最小值
4. 总键值和：左树的总键值和 + 右树的总键值和 + 当前节点值
5. 最大键值和：
   1. 左子树最大键值和、右子树最大键值和，两者取最大
   2. 如果是二叉搜索子树，再和总键值和比较，取最大
