# 题目描述
给定一棵二叉树的头节点head，
返回这颗二叉树中最大的二叉搜索子树的头节点

# 题解
## 信息收集：
每棵子树收集5个信息：最小值、最大值、是否二叉搜索树、最大二叉子树大小、最大二叉子树头节点

## 空节点设置
1. 最小值：Integer.MAX_VALUE
2. 最大值：Integer.MIN_VALUE
3. 是否二叉搜索树：true
4. 最大二叉子树大小：0
5. 最大二叉子树头节点：null

## 当前节点信息封装：
1. 最小值：当前节点值、左树最小值、右树最小值，三者取最小
2. 最大值：当前节点值、左树最大值、右树最大值，三者取最大
3. 是否二叉搜索树：
    1. 左树是搜索二叉树、右树是搜索二叉树
    2. 当前节点值大于左树最大值
    3. 当前节点值小于右树最小值
4. 最大二叉子树大小：
    1. 如果当前节点是二叉搜索树：左子树最大二叉子树大小 + 右子树最大二叉子树大小 + 1
    2. 如果当前节点不是二叉搜索树：左子树最大二叉子树大小、右子树最大二叉子树大小，两者取最大 
5. 最大二叉子树头节点：
   1. 如果当前节点是二叉搜索树：当前节点
   2. 如果当前节点不是二叉搜索树：左子树最大二叉子树大小、右子树最大二叉子树大小，大的子树的头节点
