# 题目描述
判断二叉树是否是完全二叉树


# 题解
## 信息收集：
每棵子树收集3个信息：高度，是否满二叉树，是否完全二叉树
## 空节点设置
1. 高度：0
2. 是否满二叉树：true
3. 是否完全二叉树：true
## 当前节点信息封装：
1. 高度：左树高度 和 右树高度 最大值 +1
2. 是否满二叉树：
   1. 左树是满二叉树，右树是满二叉树
   2. 左树高度 和 右树高度 相等
3. 是否完全二叉树（满足任意一条就是）：
   1. 当前树是满二叉树
   2. 左树是满二叉树，右树是满二叉树，左树高度==右树高度+1
   3. 左树是满二叉树，右树是完全二叉树，左树高度==右树高度
   4. 左树是完全二叉树，右树是满二叉树，左树高度==右树高度+1
