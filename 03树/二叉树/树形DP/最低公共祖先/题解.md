# 题目描述
给定一棵二叉树的头节点head，和另外两个节点p和q。
返回p和q的最低公共祖先

# 题解
## 信息收集：
每棵子树收集3个信息：是否找到p(findP),是否找到q(findQ)，最低公共祖先节点(ans)

## 空节点设置
1. findP：false
2. findQ：false
3. ans：null

## 当前节点信息封装：
1. findP：左树上找到p 或者 右树上找到p 或者当前节点是p
2. findQ：左树上找到q 或者 右树上找到q 或者当前节点是q
3. ans：
   1. 左树上ans不为空，则为左树上的ans
   2. 右树上ans不为空，则为右树上的ans
   3. 当前节点上找到了P和Q，则为当前节点
   4. 没找到就是null
