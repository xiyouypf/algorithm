# 题目描述

第一年农场有1只成熟的母牛A，往后的每年：

1）每一只成熟的母牛都会生一只母牛

2）每一只新出生的母牛都在出生的第三年成熟

3）每一只母牛永远不会死

返回N年后牛的数量

# 题解
1. 第 n 年的牛总数‌ = ‌第 𝑛 − 1 年的牛总数‌（所有老牛都活着） + ‌第 n 年新出生的小牛数‌。
2. 新出生的小牛数‌取决于‌成熟母牛‌的数量。
3. 根据规则“新出生的母牛在第三年成熟”，意味着‌3年前‌存在的所有母牛，到了今年都已经成熟并会生一只小牛。
4. 因此，‌第 n 年新出生的小牛数‌ = ‌第 n − 3 年的牛总数‌。
最终递推公式：‌ f(n) = f(n − 1) + f(n − 3)
