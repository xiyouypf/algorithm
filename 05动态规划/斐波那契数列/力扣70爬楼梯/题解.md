# 题目描述
70 爬楼梯 https://leetcode.cn/problems/climbing-stairs/description/?utm_source=LCUS&utm_medium=ip_redirect&utm_campaign=transfer2china

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

# 题解
定义函数 f(n)，表示到达 n 阶的方法数

如果想达到第 n 阶段，那么可以从 n - 1 阶跳上来，也可以从 n - 2 阶直接跳上来

所以 f(n) = f(n - 1) + f( n - 2)
