# 题目描述
arr是货币数组，其中的值都是正数。再给定一个正数aim。
每个值都认为是一张货币，
认为值相同的货币没有任何不同，
返回组成aim的方法数
例如：arr = {1,2,1,1,2,1,2}，aim = 4
方法：1+1+1+1、1+1+2、2+2
一共就3种方法，所以返回3

# 题解：
当前以 arr = {1,2,1,1,2,1,2}，aim = 4 来解析

## 核心思路
步骤一：数组转换为每个货币有多少张,换成两个数组coins和zhangs  
步骤二：从右往左做选择，在每一个位置上决策要不要当前这个货币，以及要几张这个货币  

## base case：
当idx在arr.length的位置，超过数组长度了，这里没有货币可选了，当rest为0时，认为找到了一种方法  
即dp[arr.length][0] = 1

## 依赖关系：
idx依赖：依赖idx+1位置的选择  
rest依赖：依赖rest-zhang * arr[idx]，这里的zhang是zhangs[idx]范围内枚举行为  
dp[idx][rest]依赖：dp[idx+1][rest] 与 dp[idx+1][rest - zhan * arr[idx]]

填表顺序：大方向idx从大到小填,rest从小到大填
