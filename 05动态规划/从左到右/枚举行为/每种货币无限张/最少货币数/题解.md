# 题目描述
arr是面值数组，其中的值都是正数且没有重复。再给定一个正数aim。
每个值都认为是一种面值，且认为张数是无限的。
返回组成aim的最少货币数

# 题解：
当前以 arr = {1, 2}, aim = 15来解析

## 核心思路
从右往左做选择，在每一个位置上决策要不要当前这个货币，以及要几张这个货币

## base case：
1. 当idx在arr.length的位置，超过数组长度了，这里没有货币可选了
   1. 当rest为0时，认为不再需要货币了，返回0；  
   2. 如果rest不为0，即认为无论如何都搞不定，返回Integer.MAX_VALUE作为无效解  
2. 即dp[arr.length][0] = 0 , dp[arr.length][1~aim] = Integer.MAX_VALUE  

## 依赖关系：
idx依赖：依赖idx+1位置的选择  
rest依赖：依赖rest-zhang * arr[idx]，这里的zhang是枚举行为  
dp[idx][rest]依赖：dp[idx+1][rest] 与 dp[idx+1][rest - zhang * arr[idx]]  

填表顺序：大方向idx从大到小填,rest从小到大填
