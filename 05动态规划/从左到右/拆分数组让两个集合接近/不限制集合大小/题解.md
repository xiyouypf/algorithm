# 题目描述
给定一个正数数组arr，
请把arr中所有的数分成两个集合，尽量让两个集合的累加和接近
返回：
最接近的情况下，较小集合的累加和

# 题解：
当前以 arr = {3, 2, 4, 7, 3, 1, 7}来解析
![dp.png](dp.png)

## 核心思路
数组总和除以2得到total，这是最大限制  
其他和背包问题一个思路  
从右往左做选择，在每一个位置上决策要不要当前这个数  

## base case：
当idx在arr.length的位置，超过数组长度了，这里没有数，无论rest为多少，最大值都是0  
即dp[arr.length][0~total] = 0

## 依赖关系：
idx依赖：依赖idx+1位置的选择  
rest依赖：依赖rest-arr[idx]  
dp[idx][rest]依赖：dp[idx+1][rest] 与 dp[idx+1][rest-arr[idx]]

填表顺序：大方向idx从大到小填,rest从小到大填
