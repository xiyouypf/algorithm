# 题目描述
给定3个参数，N，M，K
怪兽有N滴血，等着英雄来砍自己
英雄每一次打击，都会让怪兽流失[0~M]的血量
到底流失多少？每一次在[0~M]上等概率的获得一个值
求K次打击之后，英雄把怪兽砍死的概率

# 题解
一共 Math.pow(M + 1, K) 种情况
用能砍死的情况数除以总数得到死亡概率

## base case
如果restK为0，且restHp小于等于0，则找到了一种情况返回1，否则返回0  
如果restK不为0，且restHp小于等于0，则剩下无论怎么砍都成立，返回Math.pow(M + 1, restK)  

## 依赖
restK步依赖于restK-1步  
restHp依赖于restHp-i，其中i是枚举行为，范围为0～M  
dp[restHp][restK]=[restHp-i][restK-1]
