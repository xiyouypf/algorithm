# 题目描述
给定一个正数n，求n的裂开方法数，
规定：后面的数不能比前面的数小
比如4的裂开方法有：
1+1+1+1、1+1+2、1+3、2+2、4
5种，所以返回5

# 题解
定义一个参数pre，一个rest，使用cur在pre~rest中枚举，选出所有的方法数

## base case
如果rest=0，则说明找到了一种方法,dp[pre][0]=1,pre范围为1~n  
如果rest=pre，则说明找到了一种方法,dp[pre][pre]=1,pre范围为1~n  

## 依赖
pre依赖于cur，其中cur是枚举行为，范围为pre～rest   
rest依赖于rest - cur，其中cur是枚举行为，范围为pre～rest  
dp[cur][rest]=dp[cur][rest - cur]
